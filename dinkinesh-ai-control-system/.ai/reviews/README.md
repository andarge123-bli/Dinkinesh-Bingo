# AI Review Reports

This directory stores AI review reports for completed or proposed work.

## Required review format

Each report should include:

- **Review ID**
- **Task ID**
- **Reviewer**
- **Scope**
- **Severity**
- **Finding**
- **Evidence**
- **Reproduction scenario**
- **Impact**
- **Recommended fix**
- **Confidence**
- **Final status**

## Severity levels

```text
CRITICAL
HIGH
MEDIUM
LOW
```

Reviewers must report evidence and should distinguish confirmed defects from assumptions or open questions. A report must not silently alter implementation or architecture.
